# BookPath AI 隐私说明（V1 小范围试用）

更新日期：2026-07-26

## 适用范围

BookPath AI 当前仅用于个人学习、课程、比赛或非商业小范围试用，不是学校正式信息系统。首批仅邀请少量测试用户，账号总数限制为 50。

## 收集和保存的信息

系统为提供个性化图书推荐，可能保存测试学号或账号、昵称、年级、专业、学习基础、目标与兴趣、课程和已读图书、对话与推荐历史、反馈、模拟预约、通知及必要操作记录。

测试期间请使用虚拟学号和昵称，不要输入身份证号、手机号、住址、支付信息、健康信息或其他无关敏感个人信息。

## 使用目的

上述信息仅用于身份登录、学习画像、馆藏推荐、学习路径、模拟预约、系统安全、故障排查和匿名效果评测，不用于广告、交易或向无关第三方出售。

## AI 服务说明

系统可能调用管理员配置的第三方大模型处理一般问答、推荐说明或标签生成。应避免向第三方模型发送真实姓名、真实学号或不必要的完整个人资料。AI 输出可能存在错误，仅供学习和图书选择参考；书目、馆藏位置与可借状态以本系统数据库或图书馆正式系统为准。

## 保存、备份与安全

生产数据保存在家庭服务器的 PostgreSQL、上传目录和向量索引中。服务采用邀请码、密码哈希、角色权限、请求限流、回环端口、HTTPS Funnel、日志轮转及定期备份。备份不包含明文密码、JWT Secret 或模型 API Key。

## 用户权利

试用用户可联系管理员申请查询、更正或删除自己的账号与相关数据，也可以停止使用服务。管理员收到请求后应核实身份并在合理时间内处理。

## 可用性与变更

家庭服务器断电、休眠、断网、系统更新或第三方服务异常时，网站可能暂时不可用。本说明会随功能、数据范围或部署方式变化而更新。若项目转为学校正式服务、商业服务或面向公众大规模开放，应暂停扩展并重新完成合规、安全和备案评估。
