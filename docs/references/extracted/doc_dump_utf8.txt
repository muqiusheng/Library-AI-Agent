R0: 一、研究目标 本项目聚焦高校智慧图书馆AI馆员服务场景，打造专注计算机专业图书的智能AI馆员，为高校计算机学科读者提供“精准、高效、懂专业”的服务，推动智慧图书馆在专业领域的服务升级，具体研究目标如下： 构建计算机专业个性化推荐模型，结合学生专业基础、学习能力与学习需求，实现图书推荐与用户能力的动态匹配，确保推荐准确率≥75%（以学生反馈及借阅转化率为验证标准）； 研发支持≥5 轮上下文记忆的多轮对话系统，适配图书检索、借阅咨询场景，实现对话意图理解准确率≥80%，保障跨轮语义连贯； 构建计算机专业图书知识库，完成至少1000本核心馆藏的整理与标注，搭建专业书籍难度体系，覆盖不同学习阶段师生需求； 开发 Web 端 AI 馆员原型系统，实现与图书馆馆藏数据库顺畅对接，系统响应时间≤2 秒，完成专业师生试点应用，确保功能可演示、可落地。 二、研究内容 围绕上述目标，具体研究内容如下： 专业图书知识库构建：收集整理计算机专业核心馆藏图书信息，梳理图书基本信息、知识点关联，结合 Qwen 大模型完成难度半自动标注及人工校验，形成结构化数据集，为推荐功能提供基础； 多轮对话与交互系统实现：基于 Qwen 大模型，结合 LangChain 框架开发上下文记忆模块，优化对话逻辑，支持多轮连续咨询，实现图书推荐、借阅咨询、学习路径咨询等场景的自然交互，解决传统咨询 “问一次、答一次” 的碎片化问题，提升用户交互体验，形成 “咨询 - 推荐 - 反馈” 的闭环。 RAG 检索与推荐引擎开发：基于 LangChain 框架搭建 RAG 检索流程，选用 Chroma 向量数据库存储图书知识库向量数据，整合 Qwen 大模型能力，优化检索逻辑，避免大模型幻觉问题，提升推荐精准度，实现图书推荐与用户需求的精准匹配，； 系统集成与落地适配：使用 Streamlit完成 Web 端交互界面开发、功能整合，开展小范围试点测试，收集用户反馈并优化，确保系统可演示、可落地。 三、拟解决的关键问题 1.	多轮对话意图继承问题：针对现有AI客服无法满足连续咨询的痛点，采用长短时记忆机制结合向量数据库，实现对话上下文高效召回，解决跨轮咨询语义断裂问题，保障多轮对话连贯，同时平衡系统响应速度与使用体验。 2.	大模型幻觉规避问题：针对大模型易生成虚假内容的痛点，通过RAG检索增强机制限定真实馆藏数据与业务规范，结合专属知识库验证，确保输出内容准确，提升系统可靠性，贴合本科生技术实现能力。 3.推荐难度适配问题：针对推荐跨度不合理、与学习阶段脱节的问题，依托计算机专业核心课程学习内容、学生学习能力与图书难度标注体系，结合 RAG 检索与 Chroma 向量数据库优化推荐逻辑，实现书籍难度与用户能力精准匹配，确保推荐内容贴合专业学习规律，提升推荐有效性。 4. 用户冷启动问题：针对新生无借阅历史数据的痛点，依托学生已修课程、学习能力等核心信息，快速构建初始用户画像，结合专业通用需求生成初始推荐，后续依托用户交互反馈持续优化推荐精度，解决冷启动难题。
