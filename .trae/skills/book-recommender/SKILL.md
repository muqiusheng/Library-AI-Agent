# Book Recommender

根据用户的背景信息和学习目标，智能推荐适合的图书资源。

## 功能特性

1. **用户画像识别**：自动识别用户的年级、专业、学习目标
2. **分层推荐**：根据不同学习阶段推荐不同难度的书籍
3. **个性化推荐理由**：为每本推荐的书生成专属理由

## 用户背景关键词映射

### 年级识别
| 用户输入 | 年级级别 |
|---------|---------|
| 大一新生/大一/大一学生 | 入门级 |
| 大二/大二学生 | 初级→中级 |
| 大三/大三学生 | 中级→进阶 |
| 大四/大四学生 | 进阶→高级 |
| 研究生/研一/研二 | 高级/专业级 |
| 自学/业余学习 | 根据具体目标判断 |

### 学习目标识别
| 用户输入 | 推荐方向 |
|---------|---------|
| 学习Java/Python/C++ | 编程入门/进阶 |
| 考研/备考 | 考试用书/真题 |
| 入门/零基础 | 入门书籍 |
| 进阶/深入 | 进阶书籍 |
| 就业/找工作 | 实战项目类书籍 |

### 专业映射

|-----------|---------|
| 计算机/软件/AI/人工智能 | 编程、算法、AI |
| 数学/统计 | 数学、统计、建模 |
| 经济/金融 | 经济、金融、投资 |

## 推荐理由模板

根据用户背景自动生成个性化推荐理由：

1. **针对大一新生**：`作为大一新生，建议从基础概念入手，这本书...`
2. **针对专业学习**：`这本书与你的专业紧密相关，适合深入学习...`
3. **针对考研备考**：`备考考研推荐这本，涵盖核心考点...`
4. **针对入门学习**：`零基础友好，讲解通俗易懂...`

## 输出格式

推荐结果应以以下格式呈现：

```
📚 为你推荐以下书籍：

**《书名》** - 作者
⭐ 推荐指数：★★★★☆
📖 难度：入门/基础/进阶/高级
💡 推荐理由：根据你的[年级/专业/目标]推荐
```

## 注意事项

1. 优先推荐经典教材和口碑好的书籍
2. 根据用户描述的难度偏好调整推荐
3. 提供多种选择（不同出版社、不同风格）
4. 推荐理由要具体，与用户背景关联
5. 如果用户提到具体书籍名称，先确认是否有库存
