书途智启 (BookPath AI) 系统四层架构全景图 技术路线与系统架构
第 1 层：用户交互层 (User Presentation Layer)
Vue 3 + TypeScript + TailwindCSS + Pinia
1 学生工作台 (Student Workspace)
多轮自然语言对话 智能书籍推荐卡片 三阶段研习路径 模拟预约通知交互
2 管理运营中台 (Admin Operation Center)
馆藏Excel清洗导入 AI多标签精准审核 向量索引构建与同步 实时多维数据看板
第 2 层：接口网关与安全屏障 (API Gateway & Security Layer)
FastAPI Gateway + Pydantic v2 + OAuth2
A 安全与统一鉴权中心
Argon2id 工业级密码哈希 JWT HS256 无状态鉴权 RBAC 双角色权限严格隔离
B 流量守卫与流式传输网关
滑动窗口高并发接口限流 CORS 严格跨域域名白名单 SSE (Server-Sent Events) 逐字流式长连接
第 3 层：核心业务服务与 AI 引擎中枢 (Core Service & AI Engine Layer)
DeepSeek-V3 / R1 + BGE-zh-v1.5 + LangChain / LlamaIndex
A 推荐与学习路径核心引擎
3类高精意图分类器 6维度量化打分体系 基础/进阶/精通三阶规划
B 用户动态画像记忆中枢
知识掌握置信度提取 阅读偏好自适应演进 敏感隐私数据沙箱锁
C 大模型与向量集成适配器
DeepSeek 深度链式推理 BGE-zh 稠密语义向量召回 幻觉抑制与格式严约束校验
第 4 层：数据持久化与知识底座 (Data Persistence & Knowledge Base)
PostgreSQL 16 + ChromaDB + Local WAL Cache
1 PostgreSQL 16 关系型核心数据库
用户鉴权与角色账户 结构化标准馆藏书目 借还物理状态与事务流水 对话上下文与审计日志
2 Chroma 高性能向量数据库
图书稠密语义向量索引 (768维) 近邻余弦相似度 (HNSW) 极速检索 增量嵌入与元数据多条件联合过滤
高可用容灾与可信机制 全链路容错降级链条：当外部商业大模型 API 出现网络抖动或未配置时，系统自动无缝切换至内部启发式规则与本地向量库，仍可 100% 独立闭环完成高质量图书推荐。
